Emergency Codes

RoghanCare is pre-configured with globally recognized medical emergency color codes, allowing your team to deploy instantly while maintaining the flexibility to add custom alerts.

CODE BLUE

Cardiac Arrest

Used for life-threatening medical emergencies such as cardiac or respiratory arrest requiring immediate resuscitation.

CODE PINK

Pediatric Emergency

Activated during pediatric or infant emergencies where rapid medical intervention is critical.

CODE ORANGE

Mass Casualty

Declared during mass casualty incidents requiring rapid coordination, triage, and resource management.

CODE PURPLE

Obstetric Emergency

Used for obstetric and maternity-related emergencies requiring immediate assistance for maternal or neonatal care.

CODE GREEN

Evacuation

Activated during partial or full evacuation situations caused by safety threats or operational emergencies.

CODE RED

Fire / Smoke

Used to report fire, smoke, or potential fire hazards requiring immediate evacuation procedures.

CODE BROWN

Hazardous Material

Declared during hazardous spills or contamination events requiring containment and safety protocols.

CODE YELLOW

Missing Person

Used for missing, vulnerable, or wandering persons requiring immediate search coordination.

CODE BLACK

Security Threat

Activated during bomb threats or suspicious packages requiring lockdown and security response.

CODE SILVER

IT Systems Failure

Used during IT system failures or cybersecurity incidents affecting operational continuity.

CODE INDIGO

Infectious Disease

Declared for infectious disease outbreaks requiring isolation and infection control measures.

CODE WHITE

Aggressive Person

Used to manage aggressive or violent individuals posing risks to staff, patients, or public safety.

Custom codes can be configured as per requirement.

  • Fully configurable escalation rules
